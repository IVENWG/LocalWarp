# LocalWarp Standalone Connector

High-performance, standalone zero-dependency local daemon providing secure REST & WebSocket IPC bridge between the Web UI and iPhone CoreDevice LocationService.

## Supported Platforms
- Windows 10 / 11 (x64)
- macOS 12+ (Apple Silicon & Intel)
- Linux (x86_64)

## Architecture
- **100% Local Key Isolation**: Pairing keys and certificates never leave the local machine.
- **Zero Driver Conflicts**: Interoperates cleanly with native Apple USB drivers.
- **WireGuard / Userspace Tunnel**: Native CoreDevice LocationService integration for iOS 17+.
